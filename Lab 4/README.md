## Условие задачи

Программа организует передачу сообщений между одним процессом **Receiver** и несколькими процессами **Sender** через общий кольцевой буфер в файле.

### 1. Процесс Receiver (Приемник)
Управляет созданием канала связи и чтением сообщений.
1.  Запрашивает имя бинарного файла и его емкость (количество записей).
2.  Создает бинарный файл для сообщений (максимальная длина сообщения — 20 символов).
3.  Запрашивает количество процессов `Sender`.
4.  Запускает указанное количество процессов `Sender`, передавая им имя файла через командную строку.
5.  Ожидает сигнал готовности от **всех** запущенных процессов `Sender`.
6.  **Работает в цикле (по команде с консоли):**
    *   Считывает сообщение из бинарного файла.
    *   Либо завершает свою работу.
    *   *Примечание:* Если файл пуст, процесс блокируется и переходит в состояние ожидания поступления нового сообщения.

### 2. Процесс Sender (Отправитель)
Посылает сообщения приемнику.
1.  Открывает файл для передачи сообщений (имя получает из аргументов командной строки).
2.  Отправляет процессу `Receiver` сигнал о готовности к работе.
3.  **Работает в цикле (по команде с консоли):**
    *   Запрашивает текст сообщения (до 20 символов) и отправляет его в файл.
    *   Либо завершает свою работу.
    *   *Примечание:* Если файл заполнен (нет свободного места для записи), процесс блокируется и переходит в состояние ожидания, пока `Receiver` не прочитает сообщение.

## Технический стек

*   **Язык:** C++ (Standard: **C++98**)
*   **Сборка:** CMake
*   **Тестирование:** Google Test (GTest)
*   **Платформа:** Windows API.
*   **Синхронизация:**
    *   Используются **Мьютексы (Mutex)** для синхронизации доступа к файлу.
    *   Используются **Семафоры (Semaphore)** для реализации логики заполненности/пустоты буфера (Full/Empty).
    *   Используются **События (Event)** для сигналов готовности процессов.
