## Условие задачи

Программа представляет собой консольный процесс, состоящий из потока `main` и нескольких экземпляров потока `marker`.

### 1. Поток Main (Управляющий)
Выполняет следующие действия:
1.  Выделяет память под массив целых чисел (размерность вводится с консоли).
2.  Инициализирует элементы массива нулями.
3.  Запрашивает количество потоков `marker` для запуска.
4.  Запускает заданное количество экземпляров потока `marker`. В качестве параметра передает каждому потоку его порядковый номер.
5.  Подает сигнал на начало работы всем потокам `marker`.
6.  **Работает в цикле:**
    *   Ждет, пока **все** потоки `marker` подадут сигналы о невозможности продолжения работы (когда наткнулись на занятую ячейку).
    *   Выводит содержимое массива на консоль.
    *   Запрашивает у пользователя порядковый номер потока `marker`, который нужно завершить.
    *   Подает выбранному потоку сигнал на завершение работы.
    *   Ждет завершения работы этого потока.
    *   Выводит обновленное содержимое массива на консоль.
    *   Подает сигнал на продолжение работы всем оставшимся потокам.
7.  Завершает работу после того, как все потоки `marker` будут остановлены.

### 2. Поток Marker (Рабочий)
Каждый экземпляр выполняет следующие действия:
1.  Ожидает сигнал от `main` на старт.
2.  Инициализирует генератор случайных чисел (`srand`), используя свой порядковый номер как seed.
3.  **Работает циклически:**
    *   Генерирует случайный индекс массива (`rand() % size`).
    *   **Если элемент массива равен 0 (свободен):**
        *   Спит 5 мс.
        *   Записывает в элемент свой порядковый номер.
        *   Спит 5 мс.
        *   Продолжает цикл.
    *   **Если элемент массива НЕ равен 0 (занят):**
        *   Выводит статистику: свой номер, количество помеченных элементов, индекс элемента, который нельзя пометить.
        *   Подает сигнал потоку `main` о невозможности продолжения работы.
        *   Ждет ответный сигнал от `main` (либо на продолжение, либо на завершение).
4.  **При получении сигнала на завершение:**
    *   Заполняет нулями все элементы массива, помеченные его номером (очищает следы).
    *   Завершает работу.
5.  **При получении сигнала на продолжение:**
    *   Возвращается к циклическому выполнению задач.

## Технический стек

*   **Язык:** C++ (Standard: **C++17**)
*   **Сборка:** CMake
*   **Тестирование:** Catch2 (v3)
*   **Синхронизация:**
    *   Используются примитивы синхронизации для управления доступом к общему массиву и координации потоков (Critical Sections, Events / Mutexes, Condition Variables).
